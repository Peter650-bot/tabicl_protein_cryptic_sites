Where TabICL stands against the published baselines

Every method the CryptoBench paper reports, on every subset it reports them on, next to this project's two zero-shot TabICLv2 variants. Metrics are computed per structure then averaged — CryptoBench's own convention — so the columns are comparable. AUPRC leads: at 5.28 % positives it is the only summary that reflects how hard the task actually is. Below the benchmark bars, a second view puts every model we ran — TabICL, LogisticRegression and RandomForest, across six feature sets and two training regimes — on one ladder.

The model ladder on CB-full

LogisticRegression and RandomForest exist on CB-full only, so they cannot join the bars above. Here every configuration sits on its own row — same features, same negatives — with one dot per model family. The horizontal spread inside a row is the model effect alone (0.027–0.061 AUPRC, and TabICL leads every one of the six conditions); the vertical distance between rows is what the features did (0.343 → 0.441) — every row is now on the same (fixed) negative sampler and the same corrected residue table, so the sampler is no longer a confound between rows.
